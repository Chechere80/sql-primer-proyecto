# sql-primer-proyecto



\# SQL - Primer Proyecto



\## 📌 Contexto



Este fue mi primer repositorio en Git, creado cuando apenas estaba

empezando a aprender tanto SQL como control de versiones. En su momento

lo hice copiando instrucciones de internet, sin entender del todo

qué hacía cada comando de Git.



Hoy, con más conocimiento de Git y GitHub, retomé este repositorio

para actualizarlo y documentarlo correctamente.



\## 🎯 Objetivo del proyecto



Practicar los fundamentos de SQL mediante un ejercicio simple:



\- Crear una tabla.

\- Insertar datos de ejemplo.

\- Realizar un cálculo básico sobre esos datos.



\## 🛠️ Tecnologías utilizadas



\- SQL

\- Git

\- GitHub



\## 📈 Estado del proyecto



✅ Proyecto inicial de aprendizaje - Finalizado.



Este repositorio se conserva como evidencia del punto de partida

en mi proceso de aprendizaje de programación y bases de datos.
